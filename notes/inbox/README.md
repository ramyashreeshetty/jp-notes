# Inbox

Drop raw class notes here. Anything goes — typed notes, photos of the
whiteboard, a screenshot, a half-finished list of words.

Nothing here is parsed until you run `/ingest`. Once ingested, the file moves
to `notes/` with a date prefix and the content gets merged into `brain/`.

Raw notes are never edited after ingest — they're the original record. If
something was transcribed wrong, fix it in `brain/`, not here.
