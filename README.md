# jp-notes

A record of what I have learned in Japanese class, and a textbook built from it.

**Read it here: https://ramyashreeshetty.github.io/jp-notes/**

Classes started 2 December 2025, four a month, one to one. The course is
conversational, so everything here is in romaji. The textbook carries hiragana
and kanji for every word I have them for, hidden behind a toggle, ready for when
I start reading.

## What is in here

| Path | What it holds |
|---|---|
| `index.html` | The textbook: every class note rearranged by topic instead of by date |
| `brain/` | What I currently know, with a confidence level per item |
| `log/` | Test results and a record of what I keep getting wrong |
| `notes/classes/` | Raw class notes, one file per date, never edited after the fact |
| `notes/slides/` | Vocabulary decks from class (みんなの日本語 初級1) |
| `notes/reference/` | The N5 verb list |
| `notes/inbox/` | Where new notes go before they are filed |

## How it works

New notes go into `notes/inbox/`. From there they are parsed into `brain/`,
filed by date into `notes/classes/`, and folded into the right topic in the
textbook. Every item carries a level from L0 (new) to L5 (solid) and a
last-tested date, so revision can be weighted towards whatever is weakest and
whatever is due.

`CLAUDE.md` holds the full protocol, the house style for the textbook and the
theme.

## The textbook

Search filters the whole book at once. The あ Script button reveals hiragana and
kanji. Sentences marked *yours* are ones I built in class rather than examples
from my teacher.
